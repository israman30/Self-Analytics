# Self Analytics - iOS Device Health Monitor

This folder contains the Xcode project source for **Self Analytics**.

For the full feature list, architecture notes, and setup instructions, see the repo-root [`README.md`](../../README.md).

## Navigation (current)
- **Tabs**: Dashboard, Data Usage, Security Scan, Settings
- **History**: Open from the Data Usage screen via the top-right **History** button (full-screen)
- **Onboarding**: A Welcome screen is shown on first launch; after that the app may prompt for optional notification permissions

## Requirements
- iOS **17.0**+
- **Xcode 16**+

## Run
1. Open `../Self Analytics.xcodeproj` in Xcode.
2. Select your development team for the app target and widget extension target.
3. Build and run on a device or simulator.
